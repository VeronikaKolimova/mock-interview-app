# RAG для Вакансий (Data Scientist, ML Engineer, Data Analyst)

## 📋 Обзор

В проект добавлена **RAG-система (Retrieval-Augmented Generation)** для умной работы с вакансиями. Система помогает интервьюеру задавать более релевантные вопросы, основываясь на требованиях вакансии и ответах кандидата.

## 🎯 Что было добавлено

### 1. Новый сервис: `services/rag_service.py`

**Основные возможности:**
- ✅ Встроенные шаблоны вакансий для 3 ролей:
  - Data Scientist
  - ML Engineer  
  - Data Analyst
- ✅ Автоматическое разбиение текста вакансии на смысловые чанки
- ✅ Семантический поиск релевантных требований
- ✅ Поддержка пользовательских вакансий
- ✅ Две модели эмбеддингов:
  - **sentence-transformers** (качественная, мультиязычная)
  - Упрощённая мешок-слов (резервная)

**Ключевые методы:**
```python
# Добавить вакансию в индекс
rag_service.add_vacancy(vacancy_text, role="ML Engineer", source="user_upload")

# Поиск релевантных фрагментов
results = rag_service.search_relevant_chunks(
    query="опыт работы с пайплайнами",
    role_filter="ML Engineer",
    top_k=3
)

# Получить контекст для интервью
context = rag_service.get_context_for_interview(
    candidate_answer="Я использовал Docker и Kubernetes",
    vacancy_text=vacancy_text,
    role="ML Engineer"
)
```

### 2. Интеграция в основной API (`main.py`)

## 🔧 Как это работает

### Архитектура RAG

```
1. Загрузка вакансии
   └─> Разбиение на чанки (по 300 символов)
       └─> Вычисление эмбеддингов
           └─> Сохранение в индекс

2. Ответ кандидата
   └─> Поиск релевантных чанков (косинусное сходство)
       └─> Формирование контекста
           └─> Передача в LLM для генерации вопроса
```

### Пример использования в интервью

**Сценарий:**
1. Кандидат отвечает: *"Я разрабатывал рекомендательные системы на PyTorch"*
2. RAG находит в вакансии требования:
   - "Опыт работы с Python и фреймворками глубокого обучения"
   - "Разработка и внедрение ML-моделей"
3. Интервьюер получает контекст и задаёт уточняющий вопрос:
   *"Расскажите подробнее о том, как вы оценивали качество вашей рекомендательной системы?"*

## ❓ FAQ

**Q: RAG не находит релевантные фрагменты?**
- Проверьте, что текст вакансии > 50 символов
- Убедитесь, что роль определена корректно
- Попробуйте увеличить `top_k` в поиске

**Q: sentence-transformers не загружается?**
- Это нормально, система переключится на упрощённый режим
- Для установки: `pip install sentence-transformers`

**Q: Можно ли использовать свои шаблоны вакансий?**
- Да! Просто передайте текст в `add_vacancy()` с нужной ролью
