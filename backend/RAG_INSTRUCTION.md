# 📚 RAG для вакансий: Пошаговая инструкция для новичков

## Что такое RAG?

**RAG (Retrieval-Augmented Generation)** — это технология, которая помогает находить нужную информацию из базы знаний и использовать её для ответов на вопросы.

В нашем случае RAG будет:
- Хранить вопросы и ответы по вакансиям (Data Scientist, ML Engineer, Data Analyst)
- Искать подходящие вопросы по теме интервью
- Помогать интервьюеру задавать правильные вопросы кандидату

---

## 📁 Шаг 1: Структура файлов

У нас есть 2 главных файла:

```
backend/
├── quests.csv              ← База знаний (вопросы-ответы)
└── services/
    └── rag_service.py      ← Код RAG сервиса
```

### Файл `quests.csv`
Это обычная таблица с тремя колонками:
- **role** — роль (Data Scientist, ML Engineer, Data Analyst)
- **question** — вопрос кандидату
- **answer** — правильный ответ (подсказка для интервьюера)

Пример:
```csv
role,question,answer
Data Scientist,"Что такое переобучение?","Переобучение возникает, когда модель слишком хорошо запоминает обучающие данные..."
ML Engineer,"Что такое MLOps?","MLOps — это набор практик для автоматизации жизненного цикла ML-моделей..."
```

## 🔧 Шаг 2: Как добавить свой вопрос

### Способ 1: Через Excel/Google Таблицы
1. Откройте `backend/quests.csv` в Excel или Google Sheets
2. Добавьте новую строку в конце таблицы
3. Заполните 3 колонки: role, question, answer
4. Сохраните файл

### Способ 2: Через код Python
```python
from services.rag_service import get_rag_service

# Получаем сервис
rag = get_rag_service()

# Добавляем новый вопрос
rag.add_quest(
    role="Data Scientist",
    question="Что такое градиентный спуск?",
    answer="Это алгоритм оптимизации, который минимизирует функцию потерь, двигаясь в направлении антиградиента"
)
```

## 🧪 Шаг 3: Как проверить работу RAG

Создайте файл `test_my_rag.py` в папке `backend`:

```python
from services.rag_service import get_rag_service

# Получаем сервис
rag = get_rag_service()

# Смотрим статистику
print("📊 Статистика:", rag.get_stats())

# Ищем вопросы по теме "переобучение"
results = rag.search("переобучение модели", role_filter="Data Scientist")

print("\n🔍 Найденные вопросы:")
for r in results:
    print(f"Вопрос: {r['question']}")
    print(f"Ответ: {r['answer']}")
    print(f"Релевантность: {r['relevance_score']:.2f}")
    print("---")
```

Запустите:
```bash
cd backend
python test_my_rag.py
```

## 🚀 Шаг 4: Как использовать в интервью

Когда вы проводите интервью с кандидатом:

```python
from services.rag_service import get_rag_service

rag = get_rag_service()

# Кандидат сказал, что работал с нейронными сетями
# Ищем вопросы по этой теме
questions = rag.search("нейронные сети обучение", role_filter="Data Scientist")

# Берём первый (самый релевантный) вопрос
if questions:
    print(f"Задайте вопрос: {questions[0]['question']}")
    print(f"Правильный ответ: {questions[0]['answer']}")
```

## 📝 Шаг 5: Отправка изменений на GitHub

После того как вы добавили новые вопросы в `quests.csv`:

### 1. Проверьте статус файлов
```bash
git status
```
Вы увидите, что `quests.csv` изменён (красным цветом).

### 2. Добавьте файл в коммит
```bash
git add backend/quests.csv
```

### 3. Создайте коммит (сохраните изменения)
```bash
git commit -m "Добавлены новые вопросы для Data Scientist"
```

### 4. Отправьте на GitHub
```bash
git push origin main
```

Если у вас другая ветка (не main), замените `main` на название вашей ветки:
```bash
git push origin name-of-your-branch
```

| Команда | Что делает |

## ❓ Частые вопросы

### Q: Сколько вопросов нужно добавить?
**A:** Начните с 5-10 вопросов для каждой роли. Потом постепенно дополняйте.

### Q: Можно ли добавлять вопросы на английском?
**A:** Да! Модель понимает и русский, и английский языки.

### Q: Что если модель не загружается?
**A:** RAG автоматически переключится на простой поиск по ключевым словам. Это работает хуже, но всё равно полезно.

### Q: Как удалить вопрос?
**A:** Просто удалите соответствующую строку в файле `quests.csv` и сделайте коммит.

---

## 📞 Если что-то не работает

1. Проверьте, что файл `quests.csv` лежит в папке `backend/`
2. Убедитесь, что заголовки колонок точно такие: `role,question,answer`
3. Проверьте, что нет пустых строк в начале файла

Удачи! 🎉
